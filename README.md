# Samen-ZoeterMeer-Gezond-E-spinnenweb

### Deployment
We hebben het simpel gehouden. We hebben de applicatie in HTML geschreven, zodat jullie als opdracht gever het makkelijk kunnen openen. Door te dubbelklikken op "spinnenweb.html".


### Verdere uitbreidingen:
Technische verbeteringen:
- Deployment op een server
- Data opslaan in een database en niet in de cookies
- Account functie zodat je je eigen voortgang kan bijhouden.
Algemene verbeteringen:
- Intro verhaal over wat positieve gezondheid is
- Meer vragen over elk vlak 


### Hoe is het ontwikkeld
Het is ontwikkeld doormiddel van claude code. We hebben architectuur keuzes gemaakt om het zo simpel mogelijk te maken, zodat het simpel blijft en het voor mensen makkelijk is om te updaten. Verder is het alleen in HTML geschreven, zodat het ook te lezen is door mens en makkelijk kleine aanpassingen te maken. Met claude en andere AI modellen zou je een makkelijke uitleg kunnen krijgen hoe je het verder zou kunnen ontwikkelen.
